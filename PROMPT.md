Earlier in the same session, the films above were produced and gathered on the [Nokta'nın Filmleri](https://hakanatas.github.io/nokta-filmleri/) page. Earlier requests set two expectations: the film should be easy for 5th graders to follow, and it should use the ink style of the first film. This prompt continues in curriculum order to the last outcome of the theme, MAT.5.3.7: building triangles from a pair of crossing circles.
